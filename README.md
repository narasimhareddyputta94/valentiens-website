# 💕 Valentine's Day Website 💕

A stunning, world-class Valentine's Day website with beautiful animations, interactive elements, and romantic effects.

## ✨ Features

- **Animated Hero Section** — Floating hearts, rose petals, parallax mouse effects
- **Love Story Timeline** — Beautiful scroll-animated timeline
- **Interactive Gallery** — 3D tilt effect on hover with gradient placeholders
- **Poetry Carousel** — Auto-rotating love poems with smooth transitions
- **Love Letter Envelope** — Click-to-open animated envelope with a heartfelt letter
- **Promises Section** — Glassmorphism cards with reveal animations
- **"Reasons I Love You"** — Interactive heart button with 50 unique reasons
- **Music Visualizer** — Animated vinyl record and equalizer bars
- **Canvas Particle Hearts** — Floating heart particles across the entire page
- **Sparkle Effects** — Click anywhere for heart sparkle bursts
- **Heart Mouse Trail** — Hearts follow your cursor
- **Counter Animation** — Animated counting numbers
- **Scroll Reveal** — Elements animate into view on scroll
- **Custom Cursor** — Heart emoji follows the mouse
- **Konami Code Easter Egg** — ↑↑↓↓←→←→BA for a mega heart explosion!
- **Fully Responsive** — Works beautifully on all devices
- **Glassmorphism Design** — Modern frosted glass card effects

## 🚀 Getting Started

Simply open `index.html` in any modern browser — no build tools needed!

```bash
# Or serve locally
python3 -m http.server 8080
```
